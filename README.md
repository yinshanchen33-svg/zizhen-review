# 字斟 · 商品宣传文案合规自查助手

原生 HTML + CSS + JavaScript 与 Node.js 标准库实现，无第三方依赖。默认是**本地规则演示**，不需要密钥、不上传文案。可选的模型辅助通过本机服务端调用 DeepSeek 或 OpenAI 的 Responses API；只有完成环境变量配置且页面勾选启用后才发送文案。

比赛演示请直接阅读 [三分钟固定演示与模型配置](DEMO.md)。页面上也有可展开的比赛演示步骤和“载入比赛样例”按钮。

线上公开试用见 [DEPLOYMENT.md](DEPLOYMENT.md)：已删除评审登录，已取消累计及每分钟模型试用次数限制，保留输入限制、并发保护和失败提示。提供 Render 模板及京东云/JoyCode 适配说明；没有在未部署时编造评委网址。

## 当前模型接入状态与配置

2026-11-03 更新：已实现 DeepSeek / OpenAI 两种服务端适配。新增服务商配置与模拟测试，尚未使用真实密钥联调。按 [模型接通与公网访问步骤](MODEL_SETUP.md) 配置。

首次本地配置：双击 `configure-model.command`，选择服务商后输入模型名称和对应服务商的密钥。DeepSeek 可选择 `deepseek-flash`。脚本设置 `MODEL_PROVIDER`、`OPENAI_MODEL`、`REVIEW_MODE=model`；密钥仍只保存在服务端的 `OPENAI_API_KEY` 变量，这是兼容原配置保留的变量名，不表示必须使用 OpenAI 的密钥。不要把不同服务商的密钥混用。配置后重启服务。

页面默认不勾选模型；“服务端已配置”只表示配置就绪，尚未调用。勾选并点击开始自查后，只有收到并校验真实响应才显示“规则初筛 + 模型辅助”；失败明确回退本地规则。无配置仍可完整使用演示模式。

## 直接分享与模型配置

- 给别人离线试用：运行 `./start.command --offline`，只发送 `release/字斟离线演示.html`。接收者需下载并选择浏览器打开，聊天软件预览可能仍显示源码。这个文件内嵌样式与脚本，只使用规则，不包含模型密钥。
- 启用真实模型：双击 `configure-model.command`，在自己的终端选择服务商并填写模型名称和密钥；密钥不回显，配置写入权限为 600 的 `.env.local`。不要录屏或将配置文件发送给别人。
- 检查配置：`./start.command --check-model` 不访问供应商。`./start.command --live-model` 发送一条内置日用品样例；可能产生一次模型费用，仅输出脱敏的成功/失败状态。
- 保存配置后重启 `start.command`。页面勾选模型复核，再点击开始；只有收到并验证模型响应后才显示模型辅助模式。
- 给评委在线使用：按 DEPLOYMENT.md 发布完整服务，分享实际 HTTPS 地址；离线 HTML 和本机地址都不能替代公网智能体链接。

## 启动

最简单：双击本目录的 `index.html`，使用 Chrome、Edge 或 Safari 打开。支持本地规则、导航和导出；模型辅助必须通过本地服务启动。

本地服务（推荐，本机已提供启动脚本）：

```sh
cd '/Users/mac/Desktop/ 竞赛agent'
./start.command
```

也可以在 Finder 中双击 `start.command`。看到启动提示后访问 http://127.0.0.1:4173 。保持终端运行，按 Ctrl+C 停止。

已安装 Node.js 24 的其他电脑：

```sh
node server.mjs
# 或 npm start（无需 npm install）
```

`start.command` 优先使用系统 Node.js；本机没有时使用 Codex 自带 Node.js。这个备用路径仅适用于已安装该运行环境的 Mac。找不到运行环境时，直接打开 `index.html` 即可。

端口被占用时运行 `PORT=4174 ./start.command`，改为访问 http://127.0.0.1:4174 。服务仅监听 127.0.0.1，不对局域网公开。

## 测试

```sh
./start.command --test
# 已安装 Node.js 时也可运行：
npm test
```

自动测试覆盖边界输入、特殊品类拦截、原文定位、全部规则类型、重复匹配、未知依据及官方来源引用。无需测试框架依赖。

新增服务端测试覆盖缺失配置、模拟模型成功/失败/超时/拒绝、原文校验、注入字段、密钥不回传、同源限制、静态文件白名单与并发保护。全部使用假凭据和模拟供应商响应，不消耗真实 API 额度；接口测试需要允许本机监听临时端口。模拟测试通过不等于真实模型已联调。

公开试用测试覆盖无账号访问、旧登录接口关闭、超过旧 200 次额度仍可调用、旧配置失效和密钥隔离。本次自动测试 46 项通过；模型调用为模拟，尚需上线验收。

另外提供 **50 条独立评估样例**，覆盖明显需核查、正常表达、上下文、依据不足、范围和原文定位。与单元测试分开统计，保留失败样例：

```sh
./start.command --evaluate
# 或 npm run evaluate / node evaluation/run.cjs
```

查看 [完整评估报告](evaluation/REPORT.md) 和 [样例维护与浏览器复测说明](evaluation/README.md)。退出码 1 表示发现偏差，不代表报告没有生成。样例预期是提示质量标准，不是违法/合规标注；不得将通过比例作为真实业务准确率。法规依据需单独人工核对，脚本不能判断法律适用性。

浏览器验收：

1. 空白输入点击“开始自查”：出现输入提示。
2. 点击“夸张宣传”再自查：展示绝对化、保证、数据、促销、专利等提示；每项包含原文、说明、依据、问题和改写方向。
3. 点击“客观描述”再自查：显示“未命中当前规则，不代表文案合规”。
4. 点击“超出范围”再自查：阻止普通商品分析；手动选择特殊商品或分类不确定也应阻止。
5. 输入“这款量子收纳盒”：出现“需要人工核对”，不编造具体法规。
6. 修改已分析的文案或分类：旧结果清除、导出禁用，要求重新自查。
7. 点击“复制报告”，粘贴到文本编辑器，确认包含完整原文、风险类型、解释、依据链接、人工核查问题及改写建议。剪贴板不可用或权限被拒绝时，会打开已全选的报告，提示手动复制，不会假报成功。“导出清单”弹窗也可复制报告、全选或下载文本文件。
8. 输入 `<img src=x onerror=alert(1)>最佳收纳盒`：文字被原样展示，不执行 HTML。
9. 访问“官方依据库”“使用说明”；缩小浏览器到手机宽度，检查无横向溢出。
10. 粘贴 5,001 字符：提示缩短，不静默截断；只输入英文提示语言不适用。

| tests.cjs | 规则引擎的自动回归测试 |
| start.command | Mac 启动和测试脚本 |

添加规则：在 `rules.js` 的 `RULES` 中增加独立 id、type、带 g 标记的 pattern、通俗 explanation、refs、questions、rewrite。正则不要含可造成灾难性回溯的嵌套量词；不要添加空字符串匹配。添加能够检验实际行为的测试。

`refs` 只引用 `SOURCES` 中人工打开核对过的官方文件。记录版本、核对日期和准确条项；区分征求意见稿与正式稿。没有确认依据时使用空 `refs`，说明中明确“需要人工核对”。不要自动生成法规链接或条号。

结果中的字符位置对用户按 Unicode 字符计数；引擎内部 start/end 是 JavaScript UTF-16 索引，供原文切片使用。多类提示可能命中同一片段，不代表独立风险次数。

## 范围和局限

仅处理中国大陆普通日用商品的中文文字宣传。医疗、药品、保健食品、医疗器械，以及食品、化妆品、消毒产品、农药、烟酒等专门监管品类不在范围内。商品类别选择是人工声明，关键词只能辅助发现部分线索，无法识别所有特殊商品或变体。混合商品也应转交专业人员。

规则引擎不理解完整语义；否定、引用、反讽、同音字、异体字、插入空格等可能误报或漏报。未命中不能证明合规。无法核实真实商品、检测报告、认证、许可；不覆盖完整广告、价格、消费者保护、地方或平台规则。规则不是“禁词词典”，不输出违法认定、处罚预测或合规分数。

模型辅助也可能误判。本实现只接受模型提取的原文片段、类别及固定问题编号，服务端重算位置；不让模型生成法规链接、条号或自由法律结论。模型补充项全部标“需要人工核对”，不会替代或取消原有规则提示。提示注入防护不能保证语义分类绝对正确，仍需人工核实。

密钥仅由 `process.env.OPENAI_API_KEY` 读取；模型由 `OPENAI_MODEL` 配置，`REVIEW_MODE=model` 才启用。`MODEL_PROVIDER` 仅支持 `deepseek` 或 `openai`；未设置时兼容旧配置使用 OpenAI。API 端点分别固定为 `https://api.deepseek.com/responses` 和 `https://api.openai.com/v1/responses`，不接受前端传入密钥、模型或地址。本机开发（`NODE_ENV=development`）监听 127.0.0.1，只信任回环 Host；云端只要有 `PORT` 或 `NODE_ENV=production` 就监听 0.0.0.0，`PUBLIC_ORIGIN` 可留空并改为按平台转发的 `X-Forwarded-Host` / `Host` 动态校验同源。无论哪种模式都校验 Origin 和 JSON 请求标记，不开放 CORS。模型超时 20 秒，无自动重试。不设累计和每分钟试用次数限制；默认同时最多处理 2 个模型请求，单次输入 3,000 字符。这两个保护上限可通过环境变量调整；供应商的计费与限流仍然适用。

本地 `.env.local` 自动加载并被 Git/Docker 忽略；线上只读取部署平台环境变量。评委无需账号。不再使用 SQLite 计数，也不要求应用持久盘；默认单实例，并发上限按每个进程计算。旧 `.private` 和数据库中已有的私有文件不进入发布包，也不会恢复登录功能。

服务不记录文案、密钥或供应商原始错误。请求设置 `store:false`，但这不代表供应商零保留；需要按账户设置及供应商政策评估数据处理。没有模型或调用失败时保留演示能力，页面与复制报告会如实标注运行模式。

改写只提供删减主张或补充事实的方向；不自动创造新的功效、数据和资质。占位符需人工填实，不能直接发布。文案刷新后不保留；导出文件由用户自行保管。官方链接以新标签页打开，不传递文案或来源页面信息。
